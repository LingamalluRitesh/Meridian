# ModelForge AI — Enterprise Automated Machine Learning & MLOps Studio

ModelForge AI is a high-performance, enterprise-grade Automated Machine Learning (AutoML), Deep Tabular Architecture, and MLOps Governance Platform.

## Core Capabilities
- **Deep Tabular & Foundation ML Engines**: TabNet, FT-Transformer, SAINT, ResNet-Tabular, NODE, and Dynamic Ensembles.
- **Enterprise Feature Store**: Low-latency Redis online serving, columnar offline storage, and point-in-time AS-OF joins preventing data leakage.
- **Governance & Compliance**: Automated EU AI Act Model Cards, W3C PROV-compliant lineage, and NIST AI RMF auditing.
- **Differential Privacy & Security**: DP-SGD gradient clipping, Gaussian/Laplace noise mechanisms, adversarial defense, and model watermarking.
- **Fairness & Bias Auditing**: Disparate impact detection, equalized odds mitigation, and intersectional fairness.
- **Multi-Cloud Client SDK**: Full-featured Python SDK for experiments, datasets, distributed training, and model serving.
- **Interactive Next.js 14 Studios**: Real-time training telemetry, feature drift heatmaps, fairness inspectors, and pipeline DAG visualizers.

## Quickstart
```bash
# Install dependencies
make install

# Run automated verification suite
make test

# Launch ModelForge AI unified platform
python run.py --mode all
```
